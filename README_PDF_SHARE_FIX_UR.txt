PDF FIX UPDATE

This update changes the four PDF output actions from Printing.layoutPdf (Android print-preview flow) to Printing.sharePdf.
After generating a document, Android opens the share/save chooser so the user can save the PDF or send it to a printer app.

IMPORTANT SCOPE NOTE:
This package is based on the supplied Schools-App-main (3).zip. It does NOT claim to complete the requested Staff edit permissions or Parent read-only records portal. Those require wiring the authenticated role to the app's existing student/fee/attendance/marks data and enforcing permissions in each module. Please do not treat those two items as complete in this package.

APK has not been built or tested on a physical Android device in this environment.
