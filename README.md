# School Management Mobile — Starter Project

Flutter Android starter project. School name can be edited from the dashboard settings and a school logo can be selected from the device gallery. Basic student and teacher records are saved locally using SharedPreferences.

Included starter screens: dashboard, student list/add, teacher list/add, attendance placeholder, reports placeholder, and quick action placeholders for exams/DMC and ID/result/fee cards.

**Important:** This is an initial starter ZIP, not a completed production app. DMC, ID card, result card, fee card PDF generation, attendance data entry, authentication, cloud sync, and detailed reports are not implemented yet. It has not been compiled/tested in this environment. Build APK via GitHub Actions workflow `.github/workflows/build-apk.yml`.
